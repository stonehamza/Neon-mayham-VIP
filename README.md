# Neon Mayham VIP — Online + Offline

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا (Public) على GitHub.
2. ارفع **كل** محتويات هذا المجلد (index.html و sw.js و manifest.webmanifest والأيقونات وملف .nojekyll) في جذر المستودع.
3. Settings ← Pages ← Source: `Deploy from a branch` ← Branch: `main` / `(root)` ← Save.
4. بعد دقيقة يظهر الرابط: `https://USERNAME.github.io/REPO/`

## كيف تعمل
- أول زيارة بإنترنت: تُحمَّل اللعبة وتُخزَّن في المتصفح (تظهر رسالة "جاهزة للعمل بدون إنترنت").
- بعدها تفتح من نفس الرابط بدون إنترنت. حفظ التقدم في المتصفح كالمعتاد.
- مع وجود إنترنت تُحمَّل دائمًا أحدث نسخة؛ بدونه تُستخدم النسخة المخزنة.
- عند وجود إنترنت يظهر زر **ONLINE MODE** في شاشة البداية.
- أول لاعب يدخل الغرفة يصبح المضيف، وإذا خرج ينتقل الدور تلقائيًا لأقدم لاعب. الحد الأقصى 20 لاعبًا للغرفة (الممتلئة تحوّل اللاعب الجديد لغرفة أخرى).
- لغرفة خاصة بأصدقائك: أضف `?room=اسم` للرابط، مثل `.../REPO/?room=friends`.
- كل لاعب له مظهره وأسلحته ومتاجره ومهامه المستقلة؛ المضيف لا يتحكم إلا في تشغيل الغرفة والمرور والمشاة.

## بعد رفع نسخة جديدة
افتح الرابط مرتين. رقم النسخة (`v4`) يظهر في شاشة الأونلاين وأعلى الشاشة للتأكد أنك على الجديدة. إن بقيت نسخة قديمة امسح بيانات الموقع من إعدادات المتصفح مرة واحدة.

## ملاحظات
- يلزم HTTPS (GitHub Pages يوفره).
- الاتصال مباشر بين اللاعبين (WebRTC)، وخادم PeerJS المجاني للتعارف فقط. بعض شبكات الجوال قد تفشل بدون خادم TURN.
- إيقاف المضيف للعبة (Pause) يجمّد العالم المشترك للجميع.
